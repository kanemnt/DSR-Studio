# DSR Studio

面向 **DARK SOULS: REMASTERED** 的统一修改工作台，界面参照 VS Code（深色、活动栏、侧栏、标签页、状态栏）。

- 目标：把「文本 / 参数 / 纹理 / 地图」四个域的查看与修改集中在一个工具里，而不是装一堆互不相关的小软件。
- 原则：**写入前快照、写入后回读校验、可随时回滚**；不注入进程、不触碰存档、不修改 Havok 碰撞数据。

---

## 一、快速开始

1. 把整个 `DSRStudio` 目录放在任意位置（**建议放在游戏目录之外**，避免游戏重装时被清掉）。
2. 双击 `DSRStudio.exe`。
3. 首次启动会自动定位游戏目录（`DSR_ROOT` 环境变量 → 常见 Steam 路径 → 从程序目录向上查找）；找不到会弹目录选择框，也可以随时用「文件 → 打开游戏目录」切换。
4. 左侧图标切换域，双击列表项打开文件。

## 二、功能一览

| 域 | 能做什么 | 写入 |
|---|---|---|
| **文本 / FMG** | 浏览 `msg\<语言>\*.msgbnd.dcx`，左侧列出内部字符串表（物品名、武器名、对话、提示…），右侧编辑 | ✅ 等长或更短替换，自动快照 + 回滚 |
| **参数 / PARAM** | 浏览 41 张参数表（武器、防具、法术、SpEffect…），按 paramdef 显示字段名，位域用 `✓/·` 表示；支持按 ID 搜索 | ✅ 单元格编辑 + Ctrl+S 写回 + 回读校验 |
| **纹理 / TPF** | 预览贴图（BC1/BC2/BC3/BC4/BC5/**BC7**/RGBA/BGRA/R8），导出 DDS（完整 mip 链）与 PNG | ✅ 替换贴图（需保持尺寸与格式） |
| **地图 / MSB** | 四张表：模型 / 事件 / 区域 / 部件（以不死镇为例 251 / 208 / 175 / 550） | ✅ 「部件」与「区域」的 X/Y/Z 可改 |
| **动画 / TAE** | 打开 `*.anibnd.dcx` 可看头部、动画清单（ID / 事件数 / 偏移，自校验步长 8）、原始字节 | ⬜ 事件级（类型/起止帧）未解析 |
| **事件 / EMEVD** | 事件表 + 指令级视图（**指令名（EMEDF 246 条）/ 参数**），另有原始字节视图 | ⬜ 指令尚未反汇编成表达式 |
| **模型 / FLVER** | 容器条目 + 头部检查面板 + 骨骼自校验 + 材质/MTD/贴图信息 + **结构关系图** | ✅ **替换模型文件**（校验版本/计数 → 回包 BND3 → 快照 → 回读校验） |
| **备份** | 列出 `_ModDev\snapshots\<时间戳>\` 下的快照，双击回滚 | — |

## 三、每个域看的是什么

- **FMG**：游戏里所有显示文本。ID 是程序引用的编号；「原长」是原文字数，改短会补零，**改长会被拒绝**（FMG 字符串池是定长的）。空条目是游戏原始数据本来就没有字，可用「隐藏空条目」过滤。
- **PARAM**：数值表。列名来自 `paramdef`，鼠标悬停列头可看到类型与字节数；`字段累计 = 行宽` 用于自检列偏移是否对齐（对齐时显示绿色 ✓）。
- **TPF**：贴图包。列表里的「尺寸 · 格式」就是压缩格式；BC7 由内置原生解码器处理。导出 DDS 得到的是**含完整 mip 链**的原始数据。
- **FLVER**：模型容器内的模型本体。可看头部、包围盒、骨骼（自校验）、材质与贴图槽；
  也可用「替换模型…」把 Blender/3ds Max 导出的同版本 FLVER 塞回容器（自动快照 + 回读校验）。
- **EMEVD**：事件的字节码文件；指令名取自社区 EMEDF 表（[ds1-emedf](https://soulsmods.github.io/emedf/ds1-emedf.html)），共 246 条。
- **EMEVD（原始）**：事件的字节码文件（每个地图一份 + 全局 common）。每行一个事件：ID 被地图/实体参数引用，指令数 = 该事件包含的字节码条数，指令区偏移指向起点。
- **MSB**：地图定义，四段分别是
  - 模型（MODEL）：地图引用的网格/骨架资源；
  - 事件（EVENT）：地图脚本事件的登记表；
  - 区域（POINT）：篝火、雾门、Boss 场地等触发区域，含世界坐标；
  - 部件（PARTS）：把模型摆到地图上的实例，含坐标与缩放。

## 四、安全设计

1. 只有点「保存 / 写入」才落盘；浏览与拖拽不写文件。
2. 每次写入前把原文件复制到 `_ModDev\snapshots\<时间戳>\`。
3. 写入后立即重新读取并逐字节比对，不一致自动从快照回滚。
4. 参数表写入只改行内字节，不改变表数/行数/行宽；MSB 只改 12 字节 float，文件大小不变。
5. 「备份」页可列出所有快照并一键还原。

> 注意：本工具会直接改写游戏原始文件。改动前建议自己再做一次整目录冷备份。

## 四点六、快捷修改（集成自 DSRModifier）

菜单「工具(_T) → 快捷修改（DSRModifier）」打开面板，四个一键操作：

| 按钮 | 作用 |
|---|---|
| 附魔全开 | 全部武器 isEnhance = 1 |
| 法术次数 999 | MAGIC_PARAM_ST.maxQuantity = 999 |
| 武器补正统一 99 | correctStrength/Agility/Magic/Faith = 99 |
| 防具韧性 ×2 | EQUIP_PARAM_PROTECTOR_ST.saDurability × 2 |

每个操作都走统一写路径：快照 → 写入 → 回读校验 → 失败回滚；
执行日志显示改动行数与缺失字段。命令行等价：`--quick <enhance|magic999|correct99|sa2x>`。

## 五、已知边界

| 项 | 说明 |
|---|---|
| FMG 变长编辑 | 不支持。给空条目填字、把文本改长都需要重建字符串池 |
| 参数表搜索 | 只按 ID 过滤，不支持按数值/字段名搜索 |
| 贴图替换 | 必须与目标**同尺寸、同格式**，且 DDS 需带完整 mip 链 |
| MSB 编辑 | 仅部件与区域的坐标；模型/事件只读；不触碰 Havok |
| EMEVD | 指令结构已解析（24 字节/条）+ 名称映射；但没有把参数按类型展开（如 sbyte/float 的语义） |
| FLVER | 头部/骨骼/材质可读；不含顶点与网格结构解析（回包只做容器层，不改内容） |
| 事件字段语义 | MSB 事件表的「字段1/2」尚未解出，界面上标注为未解析 |

## 六、目录结构

```
DSRStudio\
  DSRStudio.exe              主程序
  DSRStudio.dll              主程序集
  bcdec_wrap.dll             BC7 解码（自建原生，基于公共领域 bcdec）
  DSRStudio.runtimeconfig.json / deps.json
  README.md
  native\                    bcdec 源码与头文件（可重新编译）
    bcdec_wrap.c
    bcdec.h
```

重新编译 BC7 解码器（需要 gcc）：

```bash
cd native
gcc -O2 -shared -static-libgcc -o bcdec_wrap.dll bcdec_wrap.c
```

重新构建主程序（需要 .NET 8 SDK）：

```powershell
dotnet build DSRStudio.csproj -c Release
```
